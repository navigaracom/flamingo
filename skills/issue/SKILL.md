# Flamingo — issue entry

A shortcut into the flamingo workflow with the template decided up front.

1. Read `../flamingo/SKILL.md` (in this plugin's skills directory) and follow
   its workflow.
2. The tier is preselected: a single work item. Pick user-story or bug-report
   from the idea per Phase 1's rule (ask when unclear). Skip the format
   selection but keep the scale check — if the idea clearly mismatches this
   tier, offer the better-fitting template once; the user decides.
3. Everything else — interview, drafting, elaboration, export — is unchanged.
